Welcome!

You navigated to a local Kiosk using "http". That means, you are accessing it via what is presumed to be an insecure line for browsers and operating system. That makes browsers suspicious even in a local network and as a result Kiosk can be awkward to use and even limited in its functionality.
To access Kiosk properly you need to call it via a secure line, and that only works if you have installed a "Certificate Authority" (CA) in the depth of your operating system once per device. If you have not done so, yet, please go to the setup page and follow the instructions: Setup Certificate Authority.
If you have already installed the CA properly, you can continue to the secure {{ https_link }} (Bookmark that page in your browser so that you don't have to type the awkward "https" all the time.).
