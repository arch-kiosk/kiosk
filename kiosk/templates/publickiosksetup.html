Install the Kiosk Certificate Authority

What is this Kiosk CA?

The Kiosk CA certifies that the local Kiosk Server is who it pretends to be. For it to be effective it needs to be installed into your operating system or / and Browser. Don't worry this is only necessary once per device and then again in about 10 years.

How to install the Kiosk CA

How you install the Kiosk CA depends on the operating system you are using. However, you must open this very page with each device on which you want to install the CA.
On each device follow the instructions depending on operating system:
  1. Download the Kiosk CA by clicking here: Kiosk CA
  2. Open the file "kioskca.crt" in your downloads (ctrl+J opens your downloads)
  3. Depending on your browser you will get a couple of warnings that it is an executable file (well, it isn't really) and you might be asked time and again if you really want to open the file. Confirm all of it until you get to this screen:
  4. Hit "Install Certificate" and in the next step choose "local machine" if you can (you will be asked to permit RunDll32 to make changes to your computer).
  5. After that you find yourself here:
    Choose "Place all certificates in the following store" and hit the browse button.
  6. Select "Trusted Root Certificate Authorities" from the list like so:
    Hit Ok. And then Next.
  7. You get a summary page that should look like this:
    Hit "Finish" and you should get a little "The import was successful" as a reward.
  8. You can close the open certificate and everything else left over from the process. Now you can go to the secure Kiosk using {{ https_link }}
  9. You should get to the Kiosk login page and up in the address-bar find a little left of the address. Success!
Windows
iOS
  1. Note: Click here for a video tutorial showing these steps (needs an internet connection).
  2. Use Safari to do this, it saves you a step.
  3. Download the Kiosk CA by clicking here: Kiosk CA
  4. Open the file: Tap on the file. You will see a notification saying: "Profile Downloaded — Review the profile in Settings app if you want to install it."
  5. Go to Settings: Open the Settings app.
  6. Tap "Profile Downloaded": This usually appears near the top of the main Settings menu. (If you don't see it, go to General > VPN & Device Management).
  7. Install: Tap Install in the top right corner, enter your passcode, and confirm by tapping Install again.
At this point the certificate is known to the device, but iOS does not trust it for website encryption yet. To achieve this a few more steps are necessary:
  1. Open Settings.
  2. Go to General.
  3. Tap About (At the very top).
  4. Scroll to the bottom and tap Certificate Trust Settings.
  5. Under "Enable full trust for root certificates," find your CA (e.g., MyKioskRootCA).
  6. Toggle the switch ON and tap Continue to confirm.
  7. You can go back to the browser and navigate to {{ https_link }} without any warnings. Success!
macOS
  1. Download the Kiosk CA by clicking here: Kiosk CA
  2. Open your Downloads folder in Finder.
  3. Double-click on the downloaded file.
  4. macOS will automatically open the KeyChain Access app.
  5. You'll be asked where you want to add the certificate.
  6. Crucial: Change the dropdown menu from "login" or "iCloud" to "System"
  7. Click Add and enter your MacPassword to authorize the change.
At this point the certificate is known to the device, but macOS does not trust it for website encryption yet. To achieve this a few more steps are necessary:
  1. In the Keychain Access window, make sure System is selected in the left sidebar and Certificates is selected at the top.
  2. Find your certificate (e.g., MyKioskRootCA) in the list. It will likely have a red X icon.
  3. Double-click it to open the info window.
  4. Click the Trust arrow to expand that section.
  5. Set "When using this certificate" to Always Trust.
  6. Close the certificate info window (the red dot in the top-left).
  7. A final popup will ask for your password to "modify the System Trust Settings. Authorize and click Update Settings
  8. You can go back to the browser and navigate to {{ https_link }} without any warnings. Success!
Android
  1. Download the Kiosk CA by clicking here: Kiosk CA
  2. Open Settings.
  3. Go to Security & Privacy (on some devices it’s "Security" or "Biometrics and Security").
  4. Tap More Security Settings (at the bottom).
  5. IF you have "Encryption & Credentials", tap it.
    Alternatively you might have a section "Credential storage" with an option "Install from device storage". Tap that one.
  6. Select "CA Certificate". Now Android will try to scare you away from that option. Install anyway!
  7. Locate the file you downloaded in your Downloads folder and confirm the installation.
  8. You can go back to the browser (Chrome!) and navigate to {{ https_link }} without any warnings. Success!
if you use FireFox on Android, you must first install the CA Certificate as described above. Then you start FireFox and get ready for something really weird:
  1. Tap the three dots (⋮) and go to Settings.
  2. Scroll down until you find "About Firefox". Tap it.
  3. Now comes the weirdness: Tap the FireFox Logo 5 times in a row. This unlocks the "secret settings"
  4. Go back to the main Settings page
  5. A new menu item called "Secret Settings" is available. Tap it.
  6. Find the toggle for Use third party CA certificates and turn it ON.
  7. Leave the settings and now your can navigate to {{ https_link }} without any problems. Success! (But you might have to do that part after the next FireFox update again)
